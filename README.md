
# ¿Quién soy?

## Descripción
¿Quién soy? es una aplicación Android para jugar a adivinar personajes.
Al pulsar el botón "Generar personaje", la aplicación selecciona
aleatoriamente un personaje, que puede ser una persona famosa,
un animal, un personaje de dibujos animados, una película o un videojuego.

## Tecnologías utilizadas
- Kotlin para la lógica de la aplicación.
- XML para el diseño de la interfaz.
- Android Studio para el desarrollo.

## Cómo se juega
1. Abre la aplicación.
2. Pulsa "Generar personaje".
3. Intenta adivinar el personaje.
4. Cuando termine la ronda, genera otro personaje.
